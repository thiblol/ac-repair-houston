# AC Repair Houston

Website codebase for AC Repair Houston — a local HVAC service business in the Houston market.

## Stack

Next.js + TypeScript. See `CLAUDE.md` for the project conventions and the note on this
version of Next.js differing from training data — read `node_modules/next/dist/docs/`
before writing code.

## Getting started

```bash
npm install
npm run dev
```

## Deployment

Built for static export / Vercel. Configure the deploy target before first release.
